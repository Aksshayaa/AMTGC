# AMTGC — Bug Log

The repository has a single commit (`5b1b9a4`, 27 Oct 2026), so earlier debugging history is not available from git. Entries below were found by reviewing the committed files on **27 Oct 2026**. No RTL or testbench file was modified while preparing this log. Entries marked *Predicted* came from static analysis. On 27–28 Oct 2026 the predictions were checked by running every bench with Icarus Verilog 13.0 (`bash scripts/run_iverilog.sh`; logs in `sim_logs/iverilog/`). The **Verification evidence** column now cites those logs. A ModelSim confirmation is still outstanding.

**Severity:** High = invalidates verification evidence or a stated result · Medium = test gives misleading output · Low = documentation or hygiene.
**Status:** Open · Fixed (unverified) · Fixed (verified).
